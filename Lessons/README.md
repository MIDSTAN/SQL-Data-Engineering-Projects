# SQL Lessons

Short, progressive exercises build from running a first statement to understanding relational data, joins, and query execution.

```text
┌───────────┐    ┌─────────────────┐    ┌──────────────┐    ┌───────────────────┐
│ 1.9       │───▶│ 1.10            │───▶│ 1.11         │───▶│ 1.12              │
│ First SQL │    │ Data model      │    │ Join tables  │    │ Execution order   │
└───────────┘    └─────────────────┘    └──────────────┘    └───────────────────┘
```

| Folder | Topic |
| --- | --- |
| [`1.9/`](1.9/README.md) | Running a first SQL statement in VS Code |
| [`1.10/`](1.10/README.md) | Exploring tables, columns, and relational data |
| [`1.11/`](1.11/README.md) | Comparing join types and connecting job, company, and skill data |
| [`1.12/`](1.12/README.md) | Reviewing query execution with `EXPLAIN ANALYZE` |

The lessons use the `data_jobs` schema. Query results depend on having the dataset available in the SQL environment.
